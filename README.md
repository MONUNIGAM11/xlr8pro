# xlr8plus TypeScript Scaffold

This is a minimal TypeScript-based scaffold for the xlr8plus asynchronous offload proxy service.

## Usage

- Install dependencies: `npm install`
- Run in dev mode: `npm run dev`
- Build: `npm run build`
- Start (after build): `npm start`

## Structure
- `src/index.ts`: Entry point (Express server)
- `src/pipeline/`: Core pipeline components
- `src/state/`: State management components

## Improving
Start by editing or adding to the pipeline and state modules in `src/`.
